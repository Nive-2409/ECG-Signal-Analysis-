
ECG Signal Analysis System

Overview
A Python-based educational project that generates and
analyzes a simulated electrocardiogram (ECG) signal.

Features
- ECG waveform visualization
- R-peak detection
- Heart rate calculation in BPM
- RR interval calculation
- Basic signal statistics

Technologies
- Python
- NumPy
- Matplotlib

Algorithms
- Array-based signal storage
- Linear scanning for peak detection
- RR interval analysis

Installation
Install the required packages:

pip install -r requirements.txt

Run the Project
python main.py

Limitations

The current version uses simulated ECG data.
It is intended for educational purposes and is not
a medical diagnostic tool.
